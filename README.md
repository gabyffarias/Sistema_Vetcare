# Sistema VetCare

Sistema de gestão para clínica veterinária desenvolvido para a disciplina de Engenharia de Software I (UFBA).

# Arquitetura
O projeto segue o estilo arquitetural de **Monolito Modular**, dividido em domínios de negócio independentes (`auth`, `cadastros`, `agendamento`) e organizado em camadas (Apresentação, Negócio e Persistência).
